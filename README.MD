# Baile

> [!IMPORTANT]
> This is pre-alpha quality and is, at this time, only for my personal use as a pet project.
> You will probably be much better off using either:
> [Hjem](https://github.com/feel-co/hjem) or 
> [home-manager](https://github.com/nix-community/home-manager).

Baile is a Nix module for managing user profiles, similar to [Hjem](https://github.com/feel-co/hjem) and [home-manager](https://github.com/nix-community/home-manager). It provides a modular and declarative way to configure user environments, programs, files, and more.

## About the Name

The name "Baile" comes from Irish Gaelic (Gaeilge), where it means "home" or "town."

## Inspirations

Baile draws inspiration from other excellent projects in the Nix ecosystem:

- [Hjem](https://github.com/feel-co/hjem): A streamlined, elegant $HOME management system with Nix, whose name fittingly means "home" in Danish. Hjem's focus on simplicity, multi-user support, and systemd-native file management provided a strong foundation for Baile's own approach.
- [Home Manager](https://github.com/nix-community/home-manager): The pioneering user environment manager for Nix, which set the standard for modular, declarative configuration of user profiles. Many of Baile's concepts and interface ideas are inspired by Home Manager's proven design.

Those projects are awesome - you should check those out first :)

## Features

- Modular user profile management
- Program and package configuration
- XDG file management
- Activation and environment scripts
- NixOS integration
